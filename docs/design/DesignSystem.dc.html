06

Motion

One easing curve and four durations. Nothing moves in text-heavy areas except on hover. Every animation has a still equivalent.

TokenValueUsed for
ease-labcubic-bezier(.2, .6, .2, 1)All UI transitions
dur-fast160 msLink, button and nav hover
dur-base200 msEntry hover, arrow shift, nav rule
dur-enter700 ms, stagger 80 msHero only, once on load
bg-ease1 − e^(−4·dt) on progress, 1 − e^(−5·dt) on nodesBackground reconfiguration, frame-rate independent
pulse2400 ms, opacity .35 → 1Status dot only

With prefers-reduced-motion, entrance, pulse, hover travel and the background loop are all removed. The background draws one still frame.
