Scroll linkage

Position in, state out.

  1. 1

    Each page section carries a data-bg="0..3" attribute. No scroll maths lives in the section components.

  2. 2

    A passive scroll listener only sets a dirty flag. The next frame reads section rectangles once, finds the viewport's midline and interpolates between neighbouring section mid-points, giving a continuous value from 0 to 3.

  3. 3

    Progress is smoothed with a frame-rate-independent exponential ease, so fast flicks do not tear the layout. Nodes ease toward their targets, with depth-weighted parallax and a slow sinusoidal drift for physical coherence.

  4. 4

    Link opacity scales with distance, node depth and the section's quiet factor. Pulses travel left to right along links, which gives the field a direction of computation.

Implementation

React, one component, no libraries.

The engine on this canvas is already framework-agnostic. In the real build it moves into a hook, and section tracking switches from rectangles to IntersectionObserver.

<NetworkBackground density={isMobile ? 0.5 : 1} />     // fixed layer, aria-hidden
<Section id="research" data-bg="1">               // sections declare their state

useSectionProgress()   // IntersectionObserver → 0..3
useReducedMotion()     // matchMedia, live
useVisibility()        // document + canvas on-screen
React 18Viteplain CSS + tokensCanvas 2DGitHub Pages

Fallbacks: without JavaScript, the page shows the grid texture from CSS alone. With reduced motion, one still frame is drawn per state and redrawn on scroll or resize only.
